关于这套东西

HOW IT WORKS

没有任何后端

三个游戏都是单页静态文件，逻辑跑在浏览器里，不联网也能玩，因此可以直接托管在 GitHub Pages。

进度只在你手里

存档写在 localStorage，清浏览器数据即清档。没有账号、没有埋点、没有上传。

可以自己改

题库、药材、境界都写在页面里的配置对象中，改完刷新即可生效，不必构建。
